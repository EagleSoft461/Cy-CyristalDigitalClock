# Cy-Cyristal Digital Clock

Bu proje Python ile yazılmış bir dijital saat uygulamasıdır.  

## Özellikler
- Gerçek zamanlı saat göstergesi
- Basit ve kullanıcı dostu arayüz
- Çapraz platform çalışabilir

## Kurulum
1. Python 3.x yükleyin
2. Proje dosyalarını indirin veya klonlayın
```bash
git clone https://github.com/EagleSoft461/Cy-CyristalDigitalClock.git
```
